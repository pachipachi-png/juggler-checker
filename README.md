## 期待枚数の計算式（修正済み）
以前のバージョンはBIG/REGの平均獲得枚数から期待値を出そうとして計算式を誤っていました。今回、下記のシンプルな式に修正しています。

    期待差枚 = 残り回転数 × 1ゲームのベット枚数 × (機械割(%) ÷ 100 − 1)

例：機械割110%の設定で800G回すなら 800 × 3 × 0.10 = 240枚。これを設定1〜6それぞれで計算し、統計計算で出した各設定の確率で重み付け平均したものを表示しています。

## 追加した機能・変更点
- 円グラフで設定1〜6の推定確率を表示
- ぶどう回数（任意）を入力すると、多項分布の計算にぶどうも含めて精度を上げられる。チェリー重複回数は参考表示のみで計算には使っていない
- 画面の並びを「機種選び → 実戦データ入力 → 計算（統計結果＋期待枚数）→ 追加機能（ジョーク：店舗評判×イベント）」に変更
- ジョーク機能は、固定の％を単純に足し引きするのではなく、統計計算で出た「期待設定」（重み付き平均の設定値）を基準にして、店舗の評判・イベント・日付でその数値を上下にシフトする方式に変更。だめ店舗・だめテンポは低設定側へ、優良店・イベント日・5のつく日・ゾロ目は高設定側へシフトする
- 「だめ店舗」がイベントを謳っていても、店の評判に応じて補正の効きを弱める（×0.2）。「だめテンポ」は固定でマイナス方向に寄せる

## 店舗のイベント情報について（重要な制約）
「店舗×イベントで自動的に補正をかける」仕様は、個々のホールのイベント開催日を機械的に取得できる公開データベースが存在しないため、自動取得ではなくユーザー自身が「イベント日か」を申告する方式にしてあります。特定店舗のイベント情報を自動で拾いたい場合は、その店の公式サイトやSNSを個別にスクレイピングする仕組みが必要になります（ご要望があれば次のステップとして検討できます）。

## 今後の案：アナスロ連携＋LINEでの有料回答
「アナスロ」のイベント日・直近差枚データを使って「明日は熱い？」に答え、投げ銭した人にLINEで返す、というアイデアはこのツールの延長として面白いです。ただし今のところ次の2点が引っかかるので、いきなり自動化するのではなく、まず手動で試すのが現実的です。

- **アナスロのデータ利用規約を要確認**：第三者サイトのデータを自動取得・再配布する形になるため、スクレイピングが規約上OKかを先に確認する必要があります（規約NGなら自動化しない）
- **LINEでの自動応答には別途バックエンドが必要**：今の`index.html`は静的サイトなので、LINE公式アカウントのbot化にはサーバー（Webhook）が別途要ります

最初の一歩としては、コードを書かずに「LINE公式アカウントを無料で作り、投げ銭してくれた人にアナスロを見ながら手動で返信する」だけで需要があるか試せます。反応が良ければ、そこで初めて自動化を検討する流れがリスクが低いです。
